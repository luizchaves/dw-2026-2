HTML

HyperText Markup Language

O que é HTML?

HTML é a linguagem de marcação padrão utilizada para criar páginas web. Ela descreve a estrutura de uma página por meio de elementos representados por tags.

Histórico

  • 1991 — Tim Berners-Lee publica o HTML original
  • 1995 — HTML 2.0 (primeira especificação formal)
  • 1997 — HTML 3.2 e HTML 4.0
  • 1999 — HTML 4.01
  • 2014 — HTML5 torna-se recomendação oficial do W3C
  • Atual — HTML Living Standard (mantido pelo WHATWG)

Estrutura básica

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8" />
    <title>Título da página</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
  </body>
</html>

Elementos principais

Tag Descrição
<h1> – <h6> Títulos de nível 1 a 6
<p> Parágrafo de texto
<a> Hiperlink
<img> Imagem
<ul> / <ol> Lista não-ordenada / ordenada
<table> Tabela
<form> Formulário
<div> / <span> Contêineres genéricos (bloco / inline)

Elementos semânticos (HTML5)

  • <header> — cabeçalho da página ou seção
  • <nav> — navegação principal
  • <main> — conteúdo principal
  • <section> — seção temática
  • <article> — conteúdo independente
  • <aside> — conteúdo complementar
  • <footer> — rodapé da página ou seção
